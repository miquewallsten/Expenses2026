# Financial Operations Platform

Workflow-driven financial operations platform with AI-assisted configuration and modular business domains.

## Initial structure

- `apps/web` → frontend
- `apps/api` → backend
- `packages/core` → shared core business domains
- `packages/modules` → installable business modules
- `packages/shared` → shared types, utilities, UI contracts
- `docs` → architecture and implementation docs
- `infrastructure/docker` → container setup

## First module
- Employee Expenses

## Core principles
- modular monolith
- AI-assisted, not AI-controlled
- deterministic workflow and accounting controls
- multi-tenant foundation
- mobile-first UX
